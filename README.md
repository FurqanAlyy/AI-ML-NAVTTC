# AI ML NAVTTC Tasks

This repository contains a collection of Python practice tasks organized by week. Each file is a standalone exercise that focuses on a specific programming concept, problem-solving pattern, or Python scripting challenge.

## Project structure

- `Week1/` — Early set of beginner-to-intermediate Python tasks.
- `Week2/` — Additional exercises and follow-up tasks.
- `Week3/` — Mid-level problem-solving tasks.
- `Week4/` — Another set of similar tasks, likely for revision or extended practice.
- `Week5/` — Advanced task exercises.
- `Week6/` — Final task set in the current folder structure.

## Weekly overview

### Week 1
Contains tasks from `Task1.py` through `Task25.py`.

### Week 2
Contains tasks such as `Task20.py`, `Task26.py`, `Task27.py`, `Task49.py`, and `Task50.py`.

### Week 3
Contains tasks from `Task28.py` through `Task48.py`.

### Week 4
Contains another copy of the `Task28.py` to `Task48.py` progression, organized separately.

### Week 5
Contains `Task51.py` and `Task52.py`.

### Week 6
Contains `Task53.py`, `Task54.py`, and `Task55.py`.

## How to use

1. Open a task file in the editor.
2. Read the problem and understand the expected behavior.
3. Run the script with Python from the terminal, for example:

```bash
python Week1/Task1.py
```

or

```bash
python3 Week1/Task1.py
```

## Notes

- This repository is structured as a learning/workshop folder.
- Most files are independent and can be run individually.
- Some task numbers appear in multiple weeks, which may indicate revision, duplicate exercises, or different practice rounds.
